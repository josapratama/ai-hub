Universal AI Gateway Integration Guide

          

            AI Hub implements the full, 100% compliant OpenAI REST API specification (/v1/chat/completions, /v1/models, /v1/images/generations). You can drop it into any existing application simply by changing the Base URL and API Key.
          

        


        
        

          
Gateway Endpoints Directory

          

            

              
POST/v1/chat/completions

              
Chat completions with streaming, TTFT metrics, PII redaction, and intelligent failover.

            

            

              
GET/v1/models

              
Dynamic model catalog listing all enabled models across Gemini, OpenAI, OpenRouter, Mistral, Ollama, etc.

            

            

              
POST/v1/images/generations

              
Universal text-to-image generation via DALL-E, Gemini Imagen, or free Pollinations AI fallback.

            

            

              
POST/v1/audio/transcriptions

              
Audio speech-to-text (STT) transcription accepting MP3/WAV/M4A audio recordings.

            

          

        


        
        

          
          

            

              
              1. Hubungkan ke Nexus-Chat (project/nexus-chat/.env)
            

            

              
// Di file project/nexus-chat/.env:

              
OPENAI_BASE_URL="http://localhost:4000/v1"

              
OPENAI_API_KEY="aih_live_nexuschat_2026"

            

          


          
          

            

              
              2. Hubungkan ke ResumeCraft AI (project/resumecraft/.env)
            

            

              
// Di file project/resumecraft/.env:

              
AI_GATEWAY_URL="http://localhost:4000/v1"

              
AI_GATEWAY_KEY="aih_live_resumecraft_2026"
